# GitHub Setup

## Create The Repository

1. Go to GitHub.
2. Create a new private repository named `hurrair-vip-trading`.
3. Upload or push this project folder.

## Recommended Repository Structure

```text
hurrair-vip-trading/
  backend/
  mobile/
  admin/
  docs/
  .github/workflows/
```

## GitHub Actions

The backend workflow runs parser tests with Node 20.

The Flutter workflow installs Flutter, generates Android/iOS platform folders on the runner, analyzes the app, runs tests, and builds a debug Android APK.

## iOS Note

iOS source can be generated by GitHub's Flutter runner, but publishing to TestFlight or App Store still requires Apple Developer signing certificates.
